AI Agent 入门笔记（示例资料，用于测试 RAG 问答）

一、什么是 AI Agent
AI Agent（人工智能智能体）是指能够感知环境、进行自主思考、并调用工具采取行动的软件系统。它不像传统程序只能按固定流程运行，而是可以根据目标自己决定下一步做什么。常见的形态包括智能助手、自动化办公机器人、代码生成 Agent 等。

二、Agent 的核心循环
一个典型的 Agent 运行在"感知—思考—行动"的循环里：
1. 感知：获取用户输入或环境信息；
2. 思考：由大语言模型（LLM）判断当前状态、规划下一步；
3. 行动：调用工具（如搜索、读文件、写文件、发消息）改变环境；
4. 观察：拿到工具返回的结果，再次进入循环，直到任务完成。
这个循环有时也被称为 ReAct（Reasoning + Acting）。

三、什么是工具调用（Function Calling）
工具调用是 Agent 最关键的能力。大模型本身不能直接上网或操作文件，但通过 Function Calling，它可以输出"我要调用哪个函数、参数是什么"，由外部程序真正执行，再把结果反馈给模型。正是工具调用，让 Agent 从"只会聊天"变成"能干活"。

四、Agent 与 RAG 的关系
RAG（检索增强生成）经常作为 Agent 的"知识来源"。当 Agent 遇到自己不懂的私有资料问题时，会先去知识库检索相关片段，再把片段交给大模型生成答案。本项目"RAG 个人知识库问答"演示的就是这一能力：把本地文档向量化建库，提问时先检索再作答，并标注答案出处。

五、常见应用场景
- 个人知识库：把笔记、文档变成可问答的助手；
- 智能文件整理：用自然语言指令让 Agent 自动分类、归档文件；
- 代码助手：读取代码仓库、定位问题并给出修改建议；
- 客服与办公自动化：自动回复、自动填表、跨系统同步数据。
